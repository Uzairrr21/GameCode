# GameCode C++ engineering

Use this skill for C++ files and Markdown hand-offs:

1. Inspect the existing build system and neighboring code before editing.
2. Keep ownership, lifetimes, error handling, and thread-safety explicit.
3. Make the smallest change that satisfies the request.
4. Build the affected target and run focused tests before reporting completion.
5. Summarize changed files, validation, and any remaining risk in the hand-off.

This skill is an original GameCode adaptation informed by the public
[GitHub Copilot community skills](https://github.com/github/awesome-copilot)
repository. The referenced repository is MIT licensed; no source files are
copied into this project.
